# 🌐NEWSFEED PROJECT

- 👨‍👧‍👧*TEAM[B3S2]의 프로젝트는 사용자의 경험, 소식, 가치관등이 돋보이는 게시글을 공유하고 댓글로 소통하는 NEWSFEED 개발을 진행하였습니다.🔥*
  
---

##  👨‍👧‍👧TEAM[B3S2] 소개 및 역할

- 🧑‍🏫[LEDER] 한지영 : 공통 로직이 저장된 dev 관리와 뉴스피드 및 댓글에 좋아요를 달수 있는 기능 구현
- 🧑‍💻[MEMBER] 정하륜 : 뉴스피드 사용자의 휘원가입과 마이페이지 조회, 사용자 정보 수정 및 탈퇴와 팔로우 기능 구현
- 🧑‍💻[MEMBER] 원민영 : 댓글 CRUD와 사용자 검색 기능
- 🧑‍💻[MEMBER] 이상무 : 회원가입한 사용자의 인증/인가를 JWT 인증방식으로 구현
- 🧑‍💻[MEMBER] 고아람 : 뉴스피드 CRUD와 뉴스피드 HOME에 조회될 전체 사용자 뉴스피드 조회 기능 구현
---

## 🤔개발 목표

1. 뉴스피드 APP에 사용자를 등록하기 위한 회원가입과 서버에 사용자임을 인증하는 JWT 인증방식을 사용하여 로그인 및 인증/인가 구현하기
2. 서버에 인증된 사용자들의 뉴스피드 CRUD와 다른 사용자 뉴스피드에 댓글기능인 댓글 CRUD 및 작성딘 댓글에 대댓글기능인 대댓글 CRUD 구현하기
3. 사용자가 다른 사용자를 팔로잉하고 다른사용자가 팔로워할수 있는 팔로우기능 구현하기
4. 게시된 뉴스피드와 댓글, 대댓글에 좋아요 버튼을 누르고 취소할수 있는 좋아요 기능 구현하기
---

## 🛠️기술 스택

- Java 17 : NEWSFEED 개발을 진행하기 위한 프로그래밍 언어
- Spring Boot 4 : 백엔드 서버를 구축하기 위한 JAVA 프레임워크
- Postman : HTTP에서 API 요청과 인증/인가, 응답을 테스트하기 위한 도구
- JPA : JAVA환경에서 DB를 사용하기위한 프레임워크
- MySQL 8.4.7(LTS) : 개발환경에서 사용할 DB
- Docke : DB컨테이너

## 🤝개발 진행

1. 📁패키지와 파일 분리하기
- newsfeed 구조를 담은 domain 패키지 생성
- 팀 전체 공통으로 쓰일 로직이 저장된 common 패키지 생성
- domain 패키지에 개인별로 작업할 entity, repoistory, service, controller, dto 패키지별로 분리하여 각 패키지에 해당하는 파일 분리
- 공통 로직이 저장된 common 패키지 안에 작성일 수정일의 필드를 가진 파일과 http 응답 부분에 받을 상태코드 및 응답내용을 담은 파일들로 분리
  
2. 🗨️작업내용 스크럼
- dev라는 팀 코드들을 병합하는 저장소와 개인별로 작업한 코드를 저장할 브랜치생성
- 깃허브 컨벤션을 사용하여 커밋메시지와 원격저장소에 푸시후 최종 작업 결과물 PR 작성
- 팀원의 PR 확인 후 피드백과 추가사항 요청을 위한 스크럼 진행
- 스크럼 진행 후 피드백을 반영하여 작업내용 수정 및 추가사항을 작업브랜치에 병합

3. 📋작업 보드
- 노션을 활용하여 기술스택에 관한 정보 공유 및 추가된 사항 공유

4. 🎯테스트 진행 및 프로젝트 결과
- 병합 과정시 충돌여부 확인과 최종 코드 점검
- 포스트맨을 이용한 스프링부트 서버의 API로 요청하여 요구한대로 요청하고 응답받는 과정을 테스트
- 최종 테스트 완료후 dev브랜치를 메인에 병합🏆
